# TGS E-Commerce Website

Modern React + Tailwind CSS storefront for TGS, an own-brand bag business.

## Run locally

1. Install dependencies:

~~~bash
npm install
~~~

2. Start the development server:

~~~bash
npm run dev
~~~

3. Open the local URL shown in the terminal.

## Build for production

~~~bash
npm run build
~~~

The checkout flow is a front-end demo. It stores cart items in localStorage, collects order details, and shows a confirmation message without connecting to a payment gateway.
